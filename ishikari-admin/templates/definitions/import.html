The fields a definition accepts

Required fields

name
Unique workflow identifier
nodes
Map of node definitions

Optional fields

description
Human-readable description
version
Version number (auto-incremented if omitted)
inputs
Input schema with type/description/required
outputs
Output expressions referencing node outputs
metadata
Custom key-value metadata

Node fields

type
Node type (e.g., "http/get", "transform/json")
depends_on
List of node IDs this node depends on
inputs
Input values (can use mustache-style expressions)
when
Conditional execution expression
timeout_seconds
Execution timeout
max_retries
Maximum retry attempts
